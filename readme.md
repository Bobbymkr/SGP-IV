# 🚦 Enhanced Adaptive Traffic Signal Demo

This enhanced demo showcases the advanced capabilities of our Adaptive Traffic Signal Control System in a user-friendly interface designed for non-technical audiences.

## 🎯 What This Demo Shows

- **Live Interactive Traffic Simulation**: Adjust traffic volumes and see how AI adapts signal timing
- **Algorithm Comparison**: Compare traditional vs. AI-powered traffic control methods
- **Environmental & Economic Impact**: Visualize real-world benefits of smart traffic systems
- **Advanced Features**: Emergency vehicle priority, weather adaptation, and more
- **Enhanced Visualization**: Improved Demo.gif showing real-time traffic flow and adaptive signal control

## 🚀 Quick Start

1. **Run the Demo**:
   ```bash
   streamlit run enhanced_demo.py
   ```

2. **Open in Browser**:
   - Go to http://localhost:8501 (or the URL shown in terminal)

3. **Explore the Interface**:
   - Use the sidebar to navigate between sections
   - Try the "Live Interactive Demo" to experiment with traffic scenarios
   - Compare algorithms in the "Algorithm Comparison" section
   - Learn about benefits in "Impact Metrics" and "Advanced Features"

## 📋 Requirements

- Python 3.7+
- Streamlit
- NumPy
- Pandas
- Altair
- Pillow
- OpenCV

Install with:
```bash
pip install -r requirements-enhanced.txt
```
